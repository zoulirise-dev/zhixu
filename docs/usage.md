# macOS 使用指南

打开或克隆项目后，左侧可以切换项目，中间选择变更、文件或历史，右侧查看差异或编辑文件。

打开普通文件夹时，如果尚未初始化 Git，会提示“初始化并打开”。确认后创建本地 main 分支，保留已有文件和忽略规则，不会自动提交或上传；取消不改变文件夹。已有仓库可直接打开，仓库内的子目录会打开所属仓库。

## 提交与分支

在变更列表勾选本次需要提交的文件，填写说明后提交。默认提交选中文件的当前内容，不包含未勾选文件；更多菜单可开启手动暂存模式。提交并推送会先提交，然后推送当前分支全部待推送提交。

选择远程分支时优先复用已有本地跟踪分支，没有匹配时创建跟踪分支。未提交内容属于工作区；安全切换时可能随分支一起保留。切换会覆盖修改时，应用会提示选择临时收起、携带或放弃修改。

临时收起列表可查看来源分支、时间和差异，选择任意条目恢复。遇到不同内容可比较当前文件和备份；相同内容跳过。恢复后原备份保留，确认不再需要时可删除文件或整条备份。

## 获取 拉取和推送

获取更新远程跟踪信息；拉取将选定远程分支内容整合到当前分支；推送发送本地提交。只有一个远程时直接使用，多个远程时可选择推送或拉取目标。设置中的远程下拉框显示并编辑对应地址。

待推送和待拉取数量基于最近一次远程同步信息。分叉时按提示合并；发生冲突后解决文件并继续，或中止操作。取消网络操作不等于撤销已经完成的远程更新，应刷新确认状态。

## 登录

默认使用电脑已有 Git 认证。Gitee、GitLab 和自建 HTTPS 仓库需要时提示用户名和密码；服务器要求访问令牌时，在密码框填写令牌。GitHub HTTPS 支持网页授权。SSH 使用电脑已有配置。

成功认证后通过 Git 凭据助手保存，使用相同助手的其他开发工具可复用；失败的密码不保存。不要把提交姓名和邮箱当作登录账号，它们只影响提交署名。

## 编辑与历史

文件目录显示项目文件，Git 忽略项以灰色显示，可打开、编辑和使用右键操作；忽略项不会因此进入变更列表或被自动提交。忽略目录按展开层级读取，避免打开项目时遍历大型缓存目录。Git 内部的 `.git` 元数据不显示。文件目录右键支持创建、重命名、剪切、复制、粘贴、删除和忽略。普通编辑与差异预览分开显示；编辑器支持基础补全、中文输入和 Markdown 预览。按 Command+S 保存，按 Command+R 刷新。

历史可刷新、查看提交文件及差异；文件右键可查看单文件历史。恢复旧版本修改工作区；撤销共享提交使用反向提交保留历史。

设置提供中英文、主题、Git 环境、项目提交署名、远程地址和作者信息。

## 多个远程仓库与提交署名

设置中的“远程仓库”支持新增、重命名和移除。移除前会确认，只删除本项目的远程配置及对应署名预设，不删除网站仓库、本地文件或提交。

同一项目可以为 origin、gitee 等远程分别保存姓名和邮箱。在设置中选中远程，在远程仓库卡片内填写提交署名，再点击“保存项目设置”；提交前点击“提交更改”下的署名，选择要使用的身份，再提交。选择会更新本项目的 Git 姓名和邮箱，不更改电脑的全局配置，其他项目不受影响。

署名与登录认证是两回事。提交一旦生成，署名就固定了；同一条提交推送到 GitHub 和 Gitee 会保留同一个署名。选择推送目标不会自动切换署名，移除预设也不会改写历史或清空当前署名。

未保存过署名的远程默认填入电脑 Git 的全局姓名和邮箱，支持修改；已保存的远程优先显示自己的署名。远程地址和署名统一保存，“新增远程仓库”在卡片上方，重命名和移除操作在卡片内。
