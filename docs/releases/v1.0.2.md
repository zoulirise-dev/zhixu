# 枝序 v1.0.2

枝序 · 让 Git 简单一点。

## 本次更新

- 新增远程仓库管理：支持新增、重命名和确认移除，方便同一项目同步到 GitHub、Gitee。
- 每个远程可以保存提交署名；未配置时填入电脑 Git 默认姓名和邮箱，支持修改。
- 提交前可选择署名，已有提交不受影响；推送不会自动更改署名。
- 远程地址与署名合并为卡片，新增入口独立显示，重命名和移除位于卡片内。
- 优化远程选择框、输入框边框、聚焦与悬停效果。
- 提交署名使用独立浮层选择，修复姓名与邮箱重叠、展开挤动提交框的问题。
- 修复项目路径包含目录别名时，文本文件可能被误判为不可编辑的问题。
- README 增加真实界面预览和双平台下载入口。

## 安装

适用于 macOS 14+、Apple Silicon（M 系列）。下载 `Zhixu-1.0.2-macOS-arm64.dmg`，打开后将枝序拖到 Applications；已有用户可替换旧版应用。

应用和 DMG 均已完成 Developer ID 签名、Apple 公证与票据附加。

Windows 版尚未发布，Intel Mac 暂不支持。需要可用的系统 Git。

## 文件校验

同时下载 DMG 和 `.sha256` 文件，在下载目录执行：

```sh
shasum -a 256 -c Zhixu-1.0.2-macOS-arm64.dmg.sha256
```
