# 枝序 v1.0.6｜GitHub 和 Gitee 共用本地 main

- 同一项目同步到 GitHub 和 Gitee 时，点击任一远程的 `main` 都会优先切换到已有的本地 `main`。本地分支原有的跟踪关系保持不变，拉取和推送时仍可选择目标仓库。
- 分支菜单按本地和远程分组。同名时也能直接看到 `main`、`GitHub/main` 和 `Gitee/main`，省去 Git 内部用于区分名称的前缀。
- 改善英文界面在窄侧栏中的标签和标题显示。

## 下载与升级

升级前请保存正在编辑的文件并退出枝序。

| 系统 | 安装方法 |
| --- | --- |
| macOS 14 及以上，Apple 芯片 | 打开 DMG，将「枝序」拖到「应用程序」并选择替换。 |
| Windows 10/11 x64 | 运行 EXE 安装程序，沿用上次的安装目录。使用枝序需要 Git for Windows。 |

升级会保留项目列表和设置。Windows 安装程序尚未进行代码签名，系统可能提示「未知发布者」。每个安装包均附有同名 SHA-256 校验文件。
