# 枝序 v1.0.1

枝序 · 让 Git 简单一点。首个公开版本，为 macOS 提供原生 Git 工作台。

## 下载与安装

- 系统：macOS 14 或以上。
- 架构：Apple Silicon（M 系列），当前不支持 Intel Mac。
- 下载附件 `Zhixu-1.0.1-macOS-arm64.dmg`，打开后将枝序拖入 Applications。
- 应用与 DMG 已完成 Developer ID 签名、Apple 公证及票据附加。
- 需要可用的 Git；未检测到时应用会提示安装命令行工具。

## 主要功能

- 打开、创建和克隆项目；普通文件夹可确认后初始化 Git。
- 勾选文件直接提交，支持手动暂存、提交并推送。
- 分支切换、重命名、删除、合并和对比；切换前保护未提交修改。
- 多远程推送与拉取，待推送/待拉取数量及分叉提示。
- 临时收起修改的列表、差异预览、选择恢复及删除。
- 提交详情、单文件历史、恢复历史版本及反向提交。
- 冲突处理、继续与中止操作。
- 文件目录显示灰色忽略项，忽略目录按需展开；编辑器支持语法高亮、基础补全、中文输入与 Markdown 预览。
- 优先复用电脑 Git 认证，支持 GitHub 网页授权和其他 HTTPS 仓库按需登录。
- 中文/英文与浅色/深色主题。

## 当前范围

Windows 版尚未发布。编辑器支持 UTF-8 文本（最大 2 MB），基础补全不包含语言服务器或 AI 功能。服务器要求令牌或双因素认证时，需要遵循其认证规则。

## 校验

SHA-256：

```text
ffc2cc0a8d21a6e0b3dbc9297517916c6ab9f536441bfbb4ecf0f2ac4680c8c5  Zhixu-1.0.1-macOS-arm64.dmg
```

也可同时下载 `.sha256` 附件，在两份文件所在目录执行：

```sh
shasum -a 256 -c Zhixu-1.0.1-macOS-arm64.dmg.sha256
```
