# 枝序 v1.0.4 · macOS / Windows

枝序 · 让 Git 简单一点。

本次引入共用 Flutter 实现的 macOS / Windows 桌面版本，保留现有 macOS 原生 1.0.3 正式版。提供 macOS DMG 与 Windows EXE 安装版。

## 主要功能

- 勾选需要的文件直接提交，保留未勾选修改；支持高级手动暂存。
- 文件与差异预览、图片查看、语法高亮、基础补全和代码缩略图。
- 分支管理、合并和对比；切换覆盖修改前选择收起、携带或放弃。
- 历史详情、单文件历史、备份列表和恢复对比、冲突处理。
- 多远程管理和推送/拉取目标选择，复用系统 Git 认证。
- 中文/英文、深浅色主题；项目拖动排序、自定义 Windows 标题栏及系统窗口行为。

## 本轮修正

- 统一 Windows / macOS 路径处理，修复文件树与修改状态对不上、历史与图片路径读取等问题。
- 修正 CRLF 换行引起的错误修改标记、新文件首行标记及重命名后的语法高亮。
- 修复窗口交互反馈，Windows 系统窗口按钮保持默认箭头，文件和文件夹使用手型。
- 补充语言、主题和路径回归测试。

## 下载与安装

- **macOS（M 系列）**：下载 `Zhixu-1.0.4-macOS-arm64.dmg`，拖入 Applications。要求 macOS 14+；应用和 DMG 已完成 Developer ID 签名、Apple 公证与票据附加。
- **Windows（推荐）**：下载 `Zhixu-1.0.4-Windows-x64-Setup.exe`，按向导安装。支持中英文、自动沿用安装目录升级、开始菜单快捷方式、默认勾选桌面快捷方式及卸载。升级前需要保存并退出枝序，升级和卸载保留用户设置。

Windows 需要 Windows 10/11 x64 和 Git for Windows；无需安装 Flutter 或 Visual Studio。Windows 安装包尚未代码签名，可能显示发布者未知。GitHub 网页登录需要 GitHub CLI，也可使用电脑已有 Git 认证。

## 升级说明

本次使用 Flutter 共用实现，保留原生 macOS 版源码与历史安装包。从原生 1.0.3 升级后需重新添加项目，旧设置不会自动迁移；仓库文件、提交历史与系统 Git 认证不会被清除。此前使用 Flutter 测试版的用户继续使用已有偏好目录。

## 验证与限制

已通过双端静态检查与自动测试、macOS 桌面编辑/提交集成测试、Windows Release 构建和窗口操作检查。Windows 真实输入法、多屏缩放、贴靠弹层和真实 GitHub/Gitee 认证仍需实机验证，自动测试不代表所有场景均无问题。

文本编辑支持 2 MB 以内 UTF-8 文件，图片预览上限 32 MB；基础补全不包含语言服务器或 AI。

## 文件校验

每个安装文件均提供同名 `.sha256` 文件。Windows 可使用 `Get-FileHash 文件名 -Algorithm SHA256`；macOS 可运行 `shasum -a 256 -c 文件名.sha256`。
