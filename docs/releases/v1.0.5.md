# 枝序 v1.0.5｜在变更栏编辑代码，Windows 记住窗口位置

- 在变更预览点击「编辑工作区文件」，即可修改并保存代码，再勾选要提交的文件。
- 打开项目或重新进入「变更」时，默认不勾选文件。在栏目内刷新会保留已有选择。
- Windows 再次启动时恢复上次的窗口位置、大小和最大化状态。

## 从 1.0.4 升级

先保存文件并退出枝序。macOS 14 及以上的 M 系列 Mac 请打开 DMG，将枝序拖到 Applications 并选择替换。Windows 10/11 x64 请运行 EXE，安装程序会沿用之前的安装目录。两端沿用 1.0.4 的项目列表和设置。

Windows 需要 Git for Windows。安装程序尚未进行 Windows 代码签名，系统可能显示「未知发布者」。下载同名 `.sha256` 文件可核对安装包。
