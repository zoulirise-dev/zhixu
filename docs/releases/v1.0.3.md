# 枝序 v1.0.3

枝序 · 让 Git 简单一点。

## 本次更新

- 简化提交署名：设置中独立显示“本项目提交署名”，姓名和邮箱可修改。
- 没有项目署名时，读取电脑的 Git 配置；保存只影响当前项目的新提交，不修改全局配置和其他项目。
- 移除远程仓库卡片中的署名配置和提交区的多署名选择，提交区仅显示当前署名。
- 远程仓库仅管理连接地址；切换推送目标、重命名或移除远程仓库不会改变署名。
- 更新 README 和使用说明，保留 Gitee、GitHub 两个下载入口。

## 升级说明

已有用户当前生效的项目署名会保留，旧远程署名预设不再使用。提交署名与登录账号是两回事：同一条提交推送到 GitHub 和 Gitee，姓名、邮箱及提交历史保持一致。此次升级不改写已有提交。

## 安装

适用于 macOS 14+、Apple Silicon（M 系列），需要可用的系统 Git。Windows 版尚未上线，Intel Mac 暂不支持。

下载 `Zhixu-1.0.3-macOS-arm64.dmg`，打开后将“枝序”拖入 Applications。升级时先退出旧版，再替换应用。

应用与 DMG 均已完成 Developer ID 签名、Apple 公证和票据附加。

## 文件校验

同时下载 DMG 和 `.sha256` 文件，在下载目录执行：

```sh
shasum -a 256 -c Zhixu-1.0.3-macOS-arm64.dmg.sha256
```
